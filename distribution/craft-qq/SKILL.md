# 感觉检索 · 商业级美术对照表 / 美术风格大全

## 这个技能做什么

输入**一句口语化的感觉描述**（中/英皆可），输出**感受词 + 视觉风格**：

```
"下雨天一个人走在便利店门口，冷白灯光"
   → 感受词：光 / 白 / 冷光
   → 视觉风格：冰晶冷白 0.20、代尔夫特画派 0.25、灰烬寒冬 0.22 …
```

每条风格带中文名、英文名、一句话定义、父风格，以及**它命中了输入里的哪些词**——
这份命中词就是「为什么推荐它」的解释，也是拿去写生图提示词的原料。

对做游戏的人来说，最直接的用途是**美术定调**：先把「我想做那种……的感觉」翻成
一组有名字的美术方向，再把风格名与命中词喂给生图模型出概念图。

## 怎么调用（纯 HTTP，不需要装任何东西）

服务端点：`https://xiximm.cloud`。全部 JSON，支持 CORS。**当前全部免费**，
只有限速（每 IP 20 次/分钟）与每日额度，不需要注册、不需要 token。

### 核心：一句描述 → 风格

```bash
curl -s -X POST https://xiximm.cloud/v2/analyze \
  -H "Content-Type: application/json" \
  -d '{"text":"潮湿的南方夏天午后，老旧风扇在转","words":8,"styles":12}'
```

参数：

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| `text` | 是 | 1–500 字 | 一句口语描述。不要堆关键词、不要放 URL |
| `words` | 否 | 1–12（默认 8） | 返回多少个感受词 |
| `styles` | 否 | 1–30（默认 12） | 返回多少个风格 |

响应关键字段：

```json
{
  "ok": true,
  "words":  [ { "w": "冷光", "score": 1.0, "share": 17, "styles": ["luminism"] } ],
  "styles": [ { "id": "ice-crystal-pale", "name": "冰晶冷白", "en": "Ice Crystal Pale",
                "score": 0.2014, "hits": 2, "matched": ["白","冷光"],
                "def": "霜白与极浅蓝的结晶冷调空间。", "parent": null } ],
  "excluded": [],
  "direct":   [],
  "meta": { "engine": "lexicon", "matched_words": 7 }
}
```

- `styles[].matched` —— **最重要的字段**：这个风格命中了输入里的哪些词。交付时必须带上。
- `words[].share` —— 该词被多少个风格共用。**≤6 是标识词**（某风格专属），数字越大越泛。
- `direct` —— 用户直接把风格名说出来了（中/英文名）才会出现。
- `excluded` —— 被否定的词。说「不要压抑」时「压抑」会进这里，带它的风格会被降级。

### 整句零命中怎么办

词表是**逐字匹配**的：句子里必须真的出现词表里的词。所以「雨里旧香港那种潮湿的夜」
这种整句口语可能一个词都命中不了 —— 而这恰恰是最常见的输入。

服务端现在带**语义引擎**，零命中时会自动接管，返回真实语义匹配结果，
`meta.engine` 会告诉你走的是哪条：`lexicon`（词典命中）/ `engine`（语义引擎）。

如果拿到的结果词很少、分数很低，先把 `text` 换成**更具体的画面词汇**重试一次
（"潮湿的夜" → "潮湿的青石板路，霓虹灯反光"），命中率会明显上升。

### 深挖：一个词 / 一个风格

```bash
# 一个词 → 落在哪些风格、近义词、对立词
curl -s "https://xiximm.cloud/v2/links?word=冷光"

# 一个风格 → 挂了哪些词（标识词排在前面）
curl -s "https://xiximm.cloud/v2/styles/cyberpunk/words"
```

`links` 返回的 `explain` 是**属性路描述**（定义 / 视觉 / 触觉 / 情绪极性 / 搭配对象 / 近义边界），
写美术说明时可以直接引用。`opposite` 是对立词，`co_occurs` 是常一起出现的词。

### 取图（风格参考图）

```bash
# 单个风格详情 + 图 + 出处
curl -s "https://xiximm.cloud/v2/styles/cyberpunk"

# 批量取图，一次最多 5 个
curl -s "https://xiximm.cloud/v2/images?ids=cyberpunk,synthwave"
```

图带 `thumb`（320px）/ `full`（960px）、`kind`、`credit`、`license`、`source_url`。

> `kind` 有三个值：`work` 有出处的真作品（CC0）、`synthetic` AI 示意、
> `placeholder` 占位图。**`placeholder` 不能当风格样本引用。**
> 引用 `work` 的图时把 `credit` 与 `source_url` 一起带上。

## 交付纪律

1. **给风格名 + 一句话定义 + 命中了哪些词**，不要只丢一串 id。
2. 结果的性质是**风格候选与方向锚点**，不是唯一正确答案 —— 最终美术判断在人。
3. 如果命中的词明显不对路，说清这是词表命中结果，并建议换更具体的画面描述重试。

## 常见故障

| 现象 | 原因与处理 |
|---|---|
| `404 word_not_found` | 词表里没这个词。改用整句 `analyze`，别死磕单词 |
| `404 not_found` | 路径里的 `{词}` / `{id}` 占位符没替换成真实值 |
| `429` | 触发限流（每 IP 20 次/分钟），等一分钟再试 |
| `400 text_too_long` | `text` 超 500 字，截短 |
| `405 method_not_allowed` | `/v2/analyze` 只接受 POST，别用 GET |
| 返回词很少 | 换更具体的画面词汇重试，参考上一节 |

## 场景示例（游戏美术）

| 你想做的感觉 | 可以这样问 |
|---|---|
| 废墟末世探索 | 「崩溃后的城市，风把灰吹过空街」 |
| 温暖治愈的农场 | 「清晨的木质厨房，阳光照在旧桌布上」 |
| 赛博夜市 | 「雨夜霓虹，招牌在积水里化开」 |
| 东方仙侠 | 「云雾里的青绿山水，远处有飞檐」 |

拿到风格后，把**风格英文名 + `matched` 命中词**直接拼进生图提示词，比只写「赛博朋克」精确得多。
